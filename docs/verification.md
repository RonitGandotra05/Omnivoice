## Current boundaries

The default workspace persists extracted text and records in this browser's IndexedDB. It does not keep original file binaries or provide antivirus certification. Publishing explicitly shares approved extracted text with the voice platform. Local client tools cannot serve telephone calls while the browser is closed; that scenario uses the optional PostgreSQL/native tool path. Local requests are not emails, calendar bookings or automatic callbacks. Public voice now requires shared database protection and has a rolling global reservation cap. VPN/proxy changes and shared networks remain limitations of IP-based identity.

See [Next.js setup and migration](nextjs-migration.md) for environment variables, ownership expiry, provider cleanup, storage/retention boundaries and Netlify configuration. The retained Python suite passed 184 tests in the earlier implementation pass; it was not needed or rerun for the active Next.js migration.
